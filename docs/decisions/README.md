# Architecture Decision Records (ADRs)

Each file here documents one architectural decision: what was decided, 
what alternatives were considered, and why.

## Format
- Filename: `NNNN-short-title.md` (four-digit number, kebab-case title)
- Sequential numbering — never renumber, never delete
- If a decision is reversed, add a new ADR referencing the old one 
  and mark the old one's status as "Superseded by ADR NNNN"

## Statuses
- **Proposed** — under discussion
- **Accepted** — decided and in effect
- **Superseded** — replaced by a later ADR
- **Deprecated** — no longer relevant but kept for history
